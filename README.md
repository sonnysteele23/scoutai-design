# ScoutAI Design — design.scoutai.site

One-page static site for ScoutAI Design, a Honolulu web-design / local-SEO / automation studio.

- `index.html` — the page. `404.html` — not-found page.
- `assets/css/tokens.css` — every color, size, and spacing value. Change the look here.
- `assets/css/site.css` — components; references tokens only, no inline styles.
- `assets/img/work-*.jpg` — portfolio screenshots (1000×515, cropped from live sites).
- `CNAME` — custom domain for GitHub Pages.

Deploy: push to `main`; GitHub Pages serves it. DNS: CNAME `design` → `sonnysteele23.github.io` at the scoutai.site registrar.
